# Image Steganography using Flask

A Flask web application that hides secret messages inside images using LSB (Least Significant Bit) Steganography.

## Features
- Encode secret messages
- Decode hidden messages
- Password-protected encryption
- Flask web interface

## Technologies Used
- Python
- Flask
- Pillow
- Cryptography
- HTML
- CSS

## Installation

pip install -r requirements.txt

Run:

python app.py
